# Oliva Ensaladas

Sitio estático (HTML + CSS + JS) con menú, carrito y envío del pedido por WhatsApp.

## Para completar
- `assets/js/config.js` → cargar el `price` de cada ensalada (hoy `null` = "Consultá el precio").

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
